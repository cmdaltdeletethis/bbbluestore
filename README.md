# Baby Blue — Front-End Storefront

A simple and responsive baby-blue themed e-commerce storefront built as an academic front-end web development project.

## Live Demo & Repository

- **Live Website:** https://cmdaltdeletethis.github.io/bbbluestore/
- **Source Code:** https://github.com/cmdaltdeletethis/bbbluestore

## Features

- **Landing Page (`index.html`):** Hero section, featured products, and brand concept overview.
- **Interactive Catalog (`catalog.html`):** Real-time category filtering (`All`, `Desk`, `Apparel`, `Home`) and keyword search.
- **Shopping Cart:** Add/remove items, adjust quantities, and calculate subtotals across pages using `localStorage`.
- **Validated Contact Form (`contact.html`):** Client-side form validation with instant feedback alerts.

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Keyframe Animations, Media Queries)
- Bootstrap 5.3.3
- Vanilla JavaScript (ES6+ & `localStorage`)
